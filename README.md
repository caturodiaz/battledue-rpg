# Battle Due

Battle Due es un proyecto de videojuego desarrollado con Godot. Este repositorio contiene el proyecto, sus escenas, scripts, datos y recursos gráficos.

## Estado del proyecto

El desarrollo está en curso. El proyecto incluye al personaje Negotu, sus recursos de animación y una secuencia de salto con fases diferenciadas.

## Requisitos

- Godot Engine 4.7.2, versión utilizada durante el desarrollo.
- Git, para gestionar versiones y sincronizar cambios con GitHub.

## Cómo abrir el proyecto

1. Descargá o cloná este repositorio.
2. Abrí Godot Engine.
3. En el Project Manager, seleccioná **Import** o **Importar**.
4. Elegí el archivo `project.godot` de la carpeta del proyecto.
5. Abrí el proyecto y ejecutalo con el botón de reproducción.

Si ya tenés el proyecto local, abrí directamente:

`~/Escritorio/battledue_rpg/project.godot`

## Estructura del proyecto

- `assets/`: imágenes, sprites y recursos gráficos.
- `data/`: datos y configuraciones de personajes.
- `docs/`: documentación técnica y guía para continuar el desarrollo.
- `scenes/`: escenas de Godot.
- `scripts/`: lógica del juego.
- `project.godot`: configuración principal del proyecto.

## Desarrollo

Antes de modificar código o escenas, revisá `docs/DEVELOPMENT.md` y `docs/CONTINUITY_GUIDE.md`.

Trabajá sobre la versión actual de los archivos. Conservá las funcionalidades existentes y probá el juego después de cada cambio relevante.

## Control de versiones

Repositorio: https://github.com/caturodiaz/battledue-rpg

Rama principal: `main`

Para ver el estado local:

```bash
git status --short --branch
```

Para guardar y publicar cambios, revisá primero qué archivos se van a incluir. No publiques archivos temporales, credenciales ni recursos cuya distribución no esté autorizada.
